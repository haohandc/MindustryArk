# Mindustry Ark 1.0.0.1 (RC 1) — release notes

## Overview

The first release candidate for `1.0.0`. This version brings the feature set up to everything
Mindustry supports natively. It is frozen from here: only blocking fixes, and any new feature
waits for the final release.

---

## Added

| Item | Notes |
|---|---|
| **Multiplayer** | LAN games, the public server list, and hosting on the device |
| **Mod loading** | `.jar` and `.zip` mods. Put them in `Download/Mindustry Ark/` (real path `Download/com.haohandc.mindustryark/`) and select it in the game to import |
| **Floating ball · About** | A new "About" entry in the floating ball's menu, showing the version and the repository address |

---

## Changed

| Item | Notes |
|---|---|
| **Folder permission** | No longer requests permission for the system Download folder; uses an app-created folder instead. See "Added · Mod loading" |

## Fixed

| Problem | Notes |
|---|---|
| **Too many ways to import a mod** | There is now only the game's own "import mod" button. The floating ball's "导入模组" has been removed (that entry never appeared in a released version), and the app no longer scans the folder by itself |

## Installing

**An unsigned HAP will not install**

**Option 1: an installer tool (no dev environment needed, recommended)**

| Tool | Notes |
|---|---|
| [小白调试助手](https://github.com/likuai2010/auto-installer/releases/latest) | Free cross-platform HarmonyOS debugging tool — signing and installing in one step |
| [HoKit](https://github.com/yabi-zzh/HoKit/releases/latest) | One-click re-signing, device mirroring, performance monitoring, file management |

**Option 2: sign it yourself with DevEco Studio**

1. Open this project in DevEco Studio
2. `File → Project Structure → Signing Configs → Automatically generate signature`
3. `bash deploy.sh`

More detailed installation notes are in the [README](https://github.com/haohandc/MindustryArk/blob/master/README.en.md).

## Supported devices and limitations

**By device**

| Device | Self-signed install | App store |
|---|---|---|
| **Tablet** | Works | Available once the ACL is approved |
| **Phone** | Partial (see below) | **Not offered** |
| **PC · 2in1** | Untested | Untested |

- **Why there is no app store version for phones**: the executable-memory permission (ACL, `ALLOW_WRITABLE_CODE_MEMORY`) is granted to **tablets and PC / 2in1 only**. Java's JIT needs it.
- **Why a phone is "partial"**: it depends on the system version — see below. On a supported version, a self-signed install works the same as on a tablet.

**By system version**

- The app declares a minimum of **6.1.1 (API 24)**; that floor is **untested**.
- **From API 26 (HarmonyOS 7)**: a debug install is granted the supported ACL permissions **automatically** ⇒ a phone can install self-signed.
- **HarmonyOS 5 / 6**: no such mechanism; whether a self-signed install works **is untested — go by what the device does**.

**Other**

- **No achievements and no Steam Workshop** — both are Steam-platform features rather than part of the game.
- **arm64-v8a real devices only**; **emulators will not work** (x86_64 cannot run this package).
- Full list: [docs/LIMITATIONS.md](https://github.com/haohandc/MindustryArk/blob/master/docs/LIMITATIONS.md).

## About the app store

**This app is not on any app store yet** — the GitHub distribution is the only one. The plan is to
publish on **overseas app stores**; a mainland-China listing is not possible because of the
**game licence (版号) requirement**.

An application is under way for the restricted permission
`ohos.permission.kernel.ALLOW_WRITABLE_CODE_MEMORY` (ACL). Once approved it will go to **AppTest**
first, and both this RC and the eventual store release cover **HarmonyOS tablets and PC/2in1 only —
no phones**, for the reason under "Supported devices and limitations".

That permission is what lets the JIT run on a tablet; without it the Java runtime cannot start.
Approval does not change how the GitHub distribution works.
