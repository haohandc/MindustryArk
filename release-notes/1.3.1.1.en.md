# Mindustry Ark 1.3.1.1 — release notes

## Overview

> **Bundled version: `Mindustry v8 Build 160.5`** (a note in passing; unrelated to what follows)

This version adds **whole-package import and export**: one zip that carries a complete set of game
data out and back in. The launcher's own interface was rebuilt in the same release — it has entry
transitions, it steps around cutouts and curved edges, and the bottom bar uses the system's
immersive material.

---

## Added

| Item | Notes |
|---|---|
| **Whole-package export** | Packs one version's entire game data — saves, mods, schematics, settings — into a single zip, for backup or for moving to another device |
| **Whole-package import** | Pick a zip and it is applied. ⚠️ The existing data is **backed up automatically** first |
| **Where exports and backups go** | Both under a `Mindustry Ark/` folder, reachable from the system file manager, named after the version and the time |
| **Launcher entry motion** | The launcher's own screens transition rather than cutting |
| **Cutout and curved-edge handling** | The launcher lays itself out around the camera cutout and the curved edges, adjustable in Settings |
| **Bottom navigation bar** | Replaced with the system's floating-material bar |

---

## Changed

| Item | Notes |
|---|---|
| **Save row actions** | The row of buttons is replaced by three: delete, copy, move |
| **The app name is no longer hardcoded** | The About card and the diagnostics report title read it from resources instead |
| **Diagnostics report** | One separator line under the title is gone |
| **A package with no game runtime** | If the package carries no runtime, the launcher says so and disables "start game" — rather than offering a button that does nothing |

---

## Fixed

| Problem | Notes |
|---|---|
| **The bundled-game row had no guard** | In a package with no bundled game, that row was still shown |
| **Two C functions were never declared** | `setenv` and `pthread_getname_np` compiled through the implicit declarations that C99 removed — which happens to pass the arguments correctly on AArch64, so it linked and ran. That is a coincidence rather than a guarantee, and clang 16 makes it an error by default. Both are now declared, and **the generated machine code is unchanged** |
| **The SDL3 declaration disagreed with the call** | Three parameters declared, five passed. An incremental compile cache had been hiding it: **a clean clone, or clearing the cache once, fails to build**. They agree now |
| **The declaration had no imports** | `UIAbility`, `abilityAccessCtrl` and `intl` were named in that file with no import anywhere, so none of them had a definition |

## Installing

**An unsigned HAP cannot be installed directly.**

**Route 1: an installer tool (no development environment needed; recommended)**

| Tool | Notes |
|---|---|
| [小白调试助手](https://github.com/likuai2010/auto-installer/releases/latest) | A free cross-platform HarmonyOS debug tool: signs and installs in one step |
| [HoKit](https://github.com/yabi-zzh/HoKit/releases/latest) | One-click re-signing, screen mirroring, performance monitoring, file management |

**Route 2: sign it yourself in DevEco Studio**

1. Open this project in DevEco Studio
2. `File → Project Structure → Signing Configs → Automatically generate signature`
3. `bash deploy.sh`

More detail is in the [README](https://github.com/haohandc/MindustryArk#readme).

## Supported devices and limitations

**By device**

| Device | Self-signed install | App store |
|---|---|---|
| **Tablet** | Works | Planned for an overseas store |
| **Phone** | Partly works, see below | **Not offered** |
| **PC / 2-in-1** | Untested | Planned for an overseas store |

**By system version**

- The declared minimum is **6.1.1 (API 24)**. That floor is **not measured**.
- **From API 26 (HarmonyOS 7, DevEco Studio 26)**: a debug install **requests the supported ACL
  permissions automatically**, so a self-signed install works on a phone.
- **HarmonyOS 5 / 6**: that mechanism does not exist. Whether a self-signed install works there
  **is whatever the device does**.

**Other**

- The full list is in [docs/LIMITATIONS.md](https://github.com/haohandc/MindustryArk/blob/master/docs/LIMITATIONS.md).
