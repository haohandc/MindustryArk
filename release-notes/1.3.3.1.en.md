# Mindustry Ark 1.3.3.1 — release notes

> **Bundled version: `Mindustry v8 Build 160.5`**

## Overview — the 1.3.3 storage update, released

> 1.3's core task was finishing the save-management work, together with everything around storage. 1.3.3.1 also fixes a large number of hidden bugs from earlier versions.

### Foreword

Mindustry has no built-in management for multiple saves, and the saves are kept inside the app, which makes them awkward for the player to handle.

Now you can manage your save data freely, and choose where it is stored.

In short, `Mindustry Ark v1.3.3` fills in what Mindustry itself does not have:

1. Managing multiple saves across versions
2. Per-version data isolation
3. Switching where the app stores its data
4. The game's language following the system
5. In-game UI scale and **automatic** cutout padding (experimental; the UI scale default is now 150%)

(These are additions made by the launcher. Nothing in the game itself was changed.)

---

## Added

| Item | Notes |
|---|---|
| **Storage location (sandbox / external)** | The game's data can stay in the app sandbox, or live under `Download/Mindustry Ark/` — visible in the file manager, and yours to back up |
| **Switching the location moves the data with it** | The whole set is moved across; the old copy is deleted **only after everything copied successfully**, and a failure part-way leaves it untouched |
| **Dark mode** | Follow the system, or set it by hand |
| **In-game display** | The launcher writes a "UI padding" and a "UI scale" suited to this device into **the game's own settings file**; both remain editable at any time from the game's own settings screen |
| **Automatic cutout fitting (experimental)** | Derives values suited to this device's cutout and writes them into the game's settings. Off by default |
| **The game's language follows the system** | The in-game interface language follows the system language; it can also be set from the launcher |
| **Swipe to delete a game version** | Swipe a version's row on the home screen to delete it, behind a confirmation |
| **Bulk copy / move for saves** | Select a batch of saves and copy or move them to another version at once |

## Changed

| Item | Notes |
|---|---|
| **Settings are grouped** | Language, storage and display are separate sections rather than one long column |
| **The storage-location switch** | Flipping it performs the move directly, with no confirmation dialog. The switch greys out while it runs |
| **No side-by-side columns on a narrow screen** | On a phone the list and the detail pane stack |

## Fixed

<details>
<summary>All 17</summary>

| Problem | Notes |
|---|---|
| **A deleted save stayed on screen** | It only disappeared after leaving the page |
| **A batch of list rows showed stale numbers** | Rows are reused, and the counts inside them were not |
| **A dialog's "Cancel" was one size smaller** | Not the same size as the button beside it |
| **Text in a fixed-width box grew with the system font** | The box did not, so the text spilled out |
| **The game-language switch did nothing** | The country code it read was truncated, so it never matched |
| **"The data was not migrated" never appeared** | The test was wrong, so that notice did not exist in practice |
| **A move took the whole sandbox, not the game's data** | Unrelated files were carried along |
| **The settings probe could not reach the UI scale** | That row always showed the default |
| **The progress notice during import / export could not paint** | The copy ran synchronously on the UI thread, so the message never appeared |
| **Injected JVM options never reached the JVM** | A self-test channel that another writer wiped on every launch (no effect on normal play) |
| **Two stack over-reads** | `snprintf`'s return value was used as the number of bytes written |
| **A move could skip a whole subtree** | The test misreported "absent" on the external directory, so that subtree was skipped silently |
| **A failed recycle / archive said nothing** | The message belonged to the **recycle-bin screen**, while the action is taken on the **saves screen** — so the screen the player was looking at stayed empty |
| **The previous notice never went away** | It was never cleared ⇒ after a successful delete the screen was still showing the **previous error** |
| **Back did not close "import into which copy"** | With that dialog open, back passed through and closed whatever was underneath |
| **The isolation line in Settings used a stale grouping** | Just after importing or deleting a game version it still described the previous set, until the next refresh |
| **Two pickers read the disk on every redraw** | The counts shown for the import targets and the copy/move targets were computed during redraw ⇒ several directory scans per frame |

## Installing

**An unsigned HAP cannot be installed directly.**

**Using an installer tool (no development environment needed)**

| Tool | Notes |
|---|---|
| [小白调试助手](https://github.com/likuai2010/auto-installer/releases/latest) | A free cross-platform HarmonyOS debugging tool; signs and installs in one step |
| [HoKit](https://github.com/yabi-zzh/HoKit/releases/latest) | One-click re-signing, device screen mirroring, performance monitoring, file management |

To sign it yourself with DevEco Studio, the steps are in the [README](https://github.com/haohandc/MindustryArk#readme).

> [!WARNING]
> **Do not use tools like 小白调试助手 to launch the app in "game mode".**
> Starting the app in **game mode** locks it to 60 fps.

## Supported devices and limitations

| Device | Self-signed install | App store (planned) |
|---|---|---|
| **Tablet** | Works | Mindustry Ark on an overseas app store<br>Ark Launcher on the Chinese app store |
| **Phone** | Partly | Ark Launcher (a management-only tool; it cannot start the game)<br>on the Chinese app store |
| **PC · 2-in-1** | Untested | Mindustry Ark on an overseas app store<br>Ark Launcher on the Chinese app store |

- The declared minimum is **HarmonyOS 6.1.1 (API 24)**. Devices below that cannot install the app.
- From DevEco Studio 26 on, a debug install on a phone can also obtain the missing ACL permission. In theory an API 24 phone can install it self-signed as well.
- Ark Launcher is the lite branch with the bundled game removed — a game management tool rather than a game. It is not published on GitHub Releases; build it yourself from the lite branch if you want it.
- The full list is in [docs/LIMITATIONS.md](https://github.com/haohandc/MindustryArk/blob/master/docs/LIMITATIONS.md).
