# Mindustry Ark 1.3.3.2 — release notes

> **Bundled version: `Mindustry v8 Build 160.5`**

## Overview

> [!CAUTION]
> If you are on a tablet and running Mindustry Ark v1.2.0.1 – v1.3.3.1, you are
> strongly advised to update.
>
> The problem has been there since 1.2.0.1, the release that introduced the
> launcher screen. It shows up like this: the keyboard does not work when you
> enter the game **from the launcher**, as opposed to starting the game
> directly.

---

## Fixed

| Problem | Notes |
|---|---|
| **A physical keyboard did nothing in the game** | With the launcher screen showing first, the game's surface never received keyboard focus, and the system delivers key events only to the focused component. Touch was not affected |

## Installing

**An unsigned HAP cannot be installed directly.**

**Using an installer tool (no development environment needed)**

| Tool | Notes |
|---|---|
| [小白调试助手](https://github.com/likuai2010/auto-installer/releases/latest) | A free cross-platform HarmonyOS debugging tool; signs and installs in one step |
| [HoKit](https://github.com/yabi-zzh/HoKit/releases/latest) | One-click re-signing, device screen mirroring, performance monitoring, file management |

To sign it yourself with DevEco Studio, the steps are in the [README](https://github.com/haohandc/MindustryArk#readme).

> [!WARNING]
> **Do not use tools like 小白调试助手 to launch the app in "game mode".**
> Starting the app in **game mode** locks it to 60 fps.

## Supported devices and limitations

| Device | Self-signed install | App store (planned) |
|---|---|---|
| **Tablet** | Works | Mindustry Ark on an overseas app store<br>Ark Launcher on the Chinese app store |
| **Phone** | Partly | Ark Launcher (a management-only tool; it cannot start the game)<br>on the Chinese app store |
| **PC · 2-in-1** | Untested | Mindustry Ark on an overseas app store<br>Ark Launcher on the Chinese app store |

- The declared minimum is **HarmonyOS 6.1.1 (API 24)**. Devices below that cannot install the app.
- From DevEco Studio 26 on, a debug install on a phone can also obtain the missing ACL permission. In theory an API 24 phone can install it self-signed as well.
- Ark Launcher is the lite branch with the bundled game removed — a game management tool rather than a game. It is not published on GitHub Releases; build it yourself from the lite branch if you want it.
- The full list is in [docs/LIMITATIONS.md](https://github.com/haohandc/MindustryArk/blob/master/docs/LIMITATIONS.md).
